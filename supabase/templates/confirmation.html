Bestätige deine E-Mail-Adresse

Hallo,

bestätige deine E-Mail-Adresse, um deine Registrierung im ProAcademy-Portal abzuschließen.

Gib zur Anmeldung diesen sechsstelligen Code auf der Anmeldeseite des Portals ein:

{{ .Token }}

Alternativ kannst du den folgenden Link im selben Browser auf demselben Gerät öffnen, in dem du die Anmeldung angefordert hast:

E-Mail-Adresse bestätigen

Code und Link sind nur begrenzt gültig und können einmal verwendet werden. Sobald du eine Methode nutzt, wird auch die andere ungültig.

Falls du dich nicht registriert hast, kannst du die E-Mail ignorieren.
